# tablet-test

A tiny Godot 4 project (the orange-square hello test) used to prove the
tablet loop end to end:

1. Clone this repo on the tablet with MGit (HTTPS + token).
2. Open the folder as a project in the Godot Android editor.
3. Run it — the orange square should move with the keyboard.
4. Change something small, then commit and push from MGit.
5. The change should appear here on GitHub.

If all five work, the tablet is wired for real projects.
